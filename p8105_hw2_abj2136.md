## Importing and cleaning the baseline demographics data

``` r
# keeping this here to see what original variables are called before skip

baseline_raw = read_csv("data_mci/MCI_baseline.csv")

# cleaning data set

baseline_df = read_csv("data_mci/MCI_baseline.csv",
                       na = c("", ".", "NA"),
                       skip = 1) |> 
  janitor::clean_names() |> 
  mutate(
    sex = recode_values(sex, 1 ~ "male", 0 ~ "female"),
    apoe4 = recode_values(apoe4, 1 ~ "carrier", 0 ~ "non-carrier")
    ) |> 
    filter(is.na(age_at_onset) | age_at_onset > current_age)
```

The first row of the data set acted like a code book, defining what the
values meant for the variables below. I kept one read.csv line with the
raw version so I could refer back to this code, as I skipped that row
when I was cleaning my data. I had to recode the sex and apoe4 variables
to change them from numeric to male/female and carrier/noncarrier. To
filter the data to only keep those who had MCI at baseline, I kept
everyone who had age of onset = na (never developed MCI) and everyone
who developed MCI after baseline (based on if their age of MCI onset was
greater than their age at baseline(current_age variable)), as these are
the people who would be MCI free at baseline.

483 participants were recruited into the study and 479 participants were
eligible for the study. Of these participants 93 developed MCI.The
average baseline age among those who participated in the study was 65
years. 30.0% of the women in the study are APOE4 carriers.

## Importing and cleaning amyloid data

``` r
 amyloid_df = read_csv("data_mci/mci_amyloid.csv",
                       na = c("", ".", "NA", "Na"),
                       skip = 1) |> 
  janitor::clean_names() |> 
  rename(id = study_id) |> 
  pivot_longer(
    baseline:time_8,
    names_to = "time",
    values_to = "amyloid_ratio"
  )
```

First, I cleaned the data by specifying missing values, skipping the
first row with variable descriptions (so the first row was variables
names), and cleaning the names. Then, to make it possible to merge the
amyloid and baseline data, I renamed the study_id variable in the
amyloid data to match the id variable in the baseline data set.

This data set is wide, with multiple amyloid ratio measurements per
person, at different time points. To tidy it and facilitate data
analysis, I made it a longer data set, using pivot_longer to put all the
amyloid_ratio values in one column (with multiple values for each
patient id), with another variable called time to specify which
timepoint the amyloid_ratio value came from.

The final tidied dataset contains 2435 observations.
